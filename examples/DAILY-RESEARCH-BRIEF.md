# Daily Visual Art Director Research Brief

Эта инструкция предназначена для ChatGPT Automations; она не запускает задачу сама по себе. Каждый день исследуй новые (или новые для нас) UX/UI кейсы, Figma MCP docs и creative motion demos для `visual-art-director`, приоритет: commerce, лендинги, редакционный продуктовый дизайн, spatial interfaces, функциональные motion. Дай 2–4 прямых ссылки, дату, механизм, UX пользу, ограничения, авторское применение без копирования. Предложи до трёх маленьких patches с полными именами файлов из актуального репозитория и acceptance/regression сценарием, а также хотя бы один контрпример. Не заявляй автоматического обновления локального Codex. Результат должен быть полезен для отбора улучшений, а не дайджестом красивых сайтов.

Source of truth: `skills/visual-art-director/references/living-research-loop.md` и `research/ideas.json` когда реально доступны.
