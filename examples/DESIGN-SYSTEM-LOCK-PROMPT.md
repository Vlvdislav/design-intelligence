# Example — use the existing design system, do not rebrand

```text
$visual-art-director

Разработай три концепции новой страницы существующего проекта.
Файл Figma: <existing-file-url>. Библиотека дизайн-системы: <library-link>.

Работай в DS_LOCKED: сначала изучи доступные компоненты, переменные,
варианты, типографику, сетку, иконографию и утверждённые макеты.
Приложи Design System Inventory и компонентно-токенную карту.
Создавай разные UX-сценарии и выразительные композиции без самовольного
ребрендинга и новых компонентов. Варианты должны быть редактируемыми
в Figma, с desktop/mobile и состояниями взаимодействия.
Проверь слойную структуру и DS Diff. Отклонения вынеси отдельно
как PROPOSED EXTENSION для моего согласования.
Не делай frontend.
```

Этот запрос усиливает правило, но не заменяет встроенный контракт:
если проект существующий, DS_LOCKED действует и без явного упоминания.
