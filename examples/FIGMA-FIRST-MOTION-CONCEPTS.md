# Design-first experimental prompts for `$visual-art-director`

These are short *briefs*, deliberately **not** recreation-style technical specifications. Codex should generate the scene design, motions and exact parameters itself.

## A. Fresska visual discovery / three alternatives

```
$visual-art-director

Разработай 3 авторские концепции промостраницы Fresska с нашим маскотом.
Изучи ясность UX Яндекс Маркета и технологичность Ozon как функциональные ориентиры,
а KAIRN/VELL-подобные примеры — как язык арт-дирекшна и проектирования состояний.
Хочу взрослый премиальный маркетплейс, не детский лендинг. Один вариант может быть
кинематографическим, другой товарно-ориентированным, третий — совсем иным по навигации.
Придумай сцену, композицию, ассеты, типографику и осмысленные взаимодействия сам.

СНАЧАЛА: UX-сценарий + 3 визуально разные редакционные концепции в Figma,
desktop/mobile + storyboard взаимодействий + comparison board для голосования.
НЕ создавай frontend/React/HTML и не передавай разработчику до моего выбора.
```

## B. Premium fashion campaign

```
$visual-art-director

Нужны 3 новые концепции премиального fashion-лендинга.
Вдохновляйся принципом кинематографической сцены, editorial-подачи товара
и choreographed UI, но не копируй KAIRN или его материалы.
Самостоятельно создай imagery plan, hero plate и композиционный контраст.
Сделай в Figma редактируемые desktop/mobile и ключевые кадры анимаций.
Про frontend пока не думай как о deliverable.
```

## C. Product experience / virtual styling

```
$visual-art-director

Спроектируй концепцию визуального конструктора образов.
У пользователя должен быть понятный выбор образа, состояния выбора/изменения,
возможность возврата и ясное следующее действие.
Исследуй идею persistent central model + surrounding tools, но придумай
свой визуальный язык и взаимодействие под продукт.
Покажи в Figma idle, selected, transition, undo, mobile и reduced motion.
Не разрабатывай интерфейс на JavaScript: сначала согласуем дизайн.
```

## D. Before engineering

```
$visual-art-director

Мы выбрали вариант B. Сохрани художественную идею и UX-структуру.
Подготовь отредактированный Figma-дизайн и motion storyboard,
затем дай comparative QA, UX задачи для проверки и список открытых вопросов.
Не переводи в код до отдельного утверждения.
```

## Acceptance of the designer skill

A successful run produces *actual visual and editable Figma work*, when MCP and permissions are available. It does NOT merely produce 3 prose descriptions, 3 images that masquerade as editable designs, a coding spec, or a running website. A user can be shown only visual concept previews if they explicitly asked not to write in Figma. No invented file or screenshot URLs.
