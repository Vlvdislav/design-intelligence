# Готовые команды для Codex

## Генерация с нуля — коротко

```text
$visual-art-director Разработай 3 непохожие концепции мобильного приложения
для [ниша]. Пользователи: [кто]. Цель экрана: [что делают].
Сначала свежие реальные референсы, затем отдельные качественные превью через
ImageGen. Типографика с кириллицей. В Figma не записывай.
```

## Переработай конкретный макет

```text
$visual-art-director Возьми макет [ссылка на выбранный Figma frame],
сохрани важный UX, но полностью переосмысли композицию.
Сделай три самостоятельные визуальные стратегии с разными принципами
иерархии, ритма и подачи контента. Покажи визуальные варианты перед записью.
```

## Убери AI-шаблонность

```text
$visual-art-director Это выглядит шаблонно. Проведи structural diversity audit
трёх концепций: сравни архитектуру, hierarchy, media, navigation и density.
Удали дубликаты. Не лечи проблему изменением цвета и радиусов.
Покажи новую сильную альтернативу через ImageGen.
```

## Фотографии/арт-дирекшн

```text
$visual-art-director Для моего магазина косметики разработай 3 концепции
арт-дирекшна предметной фотографии, которые реально поддержат UI каталога.
Покажи три визуальные системы, затем примени наиболее подходящую к одному
и тому же экрану каталога. Без Figma пока.
```

## Только Figma (без изображений экрана)

```text
$visual-art-director Создай в Figma [URL] экран «Order confirmation».
Сначала прочитай существующую библиотеку, затем нарисуй нативный редактируемый
дизайн в отдельном фрейме. Не используй HTML и не вставляй UI как bitmap.
Проверь итоговый скриншот, текстовые стили и ограничения auto layout.
```

## Мобильный + desktop в одной системе

```text
$visual-art-director Я выбрал концепцию C. Создай в Figma [URL] два
редактируемых фрейма этой системы: mobile и desktop. Сохрани визуальную
идентичность, но перестрой информационную архитектуру под размер экрана.
Проверь длинные тексты на русском и доступность ключевых CTA.
```

## UX-аудит без изменения оригинала

```text
$visual-art-director Проведи критическое ревью текущего выбранного Figma
фрейма [URL]: визуальная иерархия, список сценариев, доступность,
типографика, точки потери контекста. Дай наблюдение → риск → конкретную
правку. Без изменений файла.
```

## Typography lab

```text
$visual-art-director Составь 3 выразительные, но прикладные беззасечковые
типографические системы для [ниша]. Покажи на русском заголовке, цене,
фильтре, двухстрочном названии товара и CTA. Не предлагай шрифт, пока
не проверил кириллицу и (при записи в Figma) фактическую доступность.
```

## Исследование актуального UI

```text
$visual-art-director Проведи research современных интерфейсов на [период],
найди 6 реальных примеров с прямыми ссылками. Выдели 4 композиционных
приёма, которые подходят [ниша], и 3 приёма, которые копировать не следует.
После исследования покажи 3 самостоятельных арт-направления.
```

# Visual Art Director 2.0 — Creative Technologist / Figma

## Spatial fashion — код только для эксперимента, Figma как итог

```text
$visual-art-director
Нужен эффектный spatial try-on hero с взаимодействиями уровня VirtualFit.
Я не хочу сам прописывать значения perspective, blur, timing и анимаций.
Сам исследуй работающие примеры, придумай оригинальную композицию,
составь Scene Blueprint и критически проверь её.
Если сложная геометрия требует рендера, сделай временный HTML/CSS/JS-прототип
в отдельной папке; проверь 5 состояний desktop + mobile screenshot.
Затем перенеси результат в Figma [URL] как редактируемые слои. Нативно
доработай кнопки, текст, карточки, варианты и панель покупки.
Покажи motion storyboard и явно отметь, что реально интерактивно в Figma.
Никакого продакшен-сайта в качестве результата.
```

## Spatial без кода — только native Figma

```text
$visual-art-director
Создай пространственную витрину коллекции в Figma [URL], **без HTML/JS**.
Оригинальная композиция, эффект глубины, чёткая коммерческая иерархия.
Сделай набор редактируемых фреймов: idle, hover, selected, transition
midpoint, settled, mobile idle, mobile selected. К каждой анимации
добавь trigger, timing, easing и reduced-motion fallback.
Проверь экспорт/скриншоты готового файла.
```

## Экспериментальная коллекция для Fresska

```text
$visual-art-director
Для Fresska придумай неочевидный, но коммерчески жизнеспособный способ
показа коллекции товаров: предметы как пространственная сцена, редакционная
иерархия, интерактивное исследование. НЕ копируй VirtualFit.
Учитывай существующую дизайн-систему Figma [URL], цену/наличие/варианты
товара и правила покупки. Предложи 3 разных архитектуры.
Выбери наиболее применимую, при необходимости проверь в локальном
экспериментальном прототипе и собери редактируемые desktop/mobile
фреймы и состояния в Figma. Убери стандартный AI-slop.
```

## Преврати подробное техническое ТЗ в Figma, а не в сайт

```text
$visual-art-director
Вот спецификация интерактивной сцены [вставь техническое ТЗ].
Режим exact recreation: не меняй строки, размеры, товары и тайминги молча.
Создай в Figma редактируемую композицию и отдельные ключевые состояния,
сохрани видимые детали. Сложные JS-анимации задокументируй и представь
motion storyboard, не утверждай, что импорт из HTML перенёс их в Figma.
Приложи таблицу требований: выполнено / частично / недоступно в Figma.
```

## Дизайн-режиссёр: только сильный визуал, без ответа «сделано» вслепую

```text
$visual-art-director
Найди, почему дизайн выглядит нейрослопно.
Не меняй случайно палитру: исследуй композиционную причину.
Сравни hero, типографику, масштаб, медиа, геометрию, motion, свет,
взаимодействия. Предложи новое signature moment, создай реальный
визуальный прототип/превью и повторно проверь результат по скриншоту.
Мой конечный формат: [Figma / изображения].
```
