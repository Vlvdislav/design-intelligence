# Design Lab: VirtualFit → редактируемый дизайн Figma

Это пример **тестовой задачи** для обновлённого `$visual-art-director`.
Это не исходный код VirtualFit и не утверждение, что Figma-файл уже создан.

## Задача пользователя

«Сделай сцену виртуальной примерки одежды, где человек в центре, вокруг
него spatial-дуга товаров, одежда меняется через световую scan-line,
а управление выполнено как стеклянные панели. Мне нужен редактируемый
дизайн Figma, и я не хочу указывать точную математику вручную».

## Что skill должен спроектировать самостоятельно

1. **Концепция:** spatial fashion showroom, модель как центр сцены, одежда
   как физические объекты на дуге, минимум UI поверх героя.
2. **Art direction:** дневной свет, soft bokeh, единство съёмочного ракурса,
   избирательная оптика, стеклянный материал только для функционального UI.
3. **Blueprint:** отдельные слои `Background / Editorial word / Arc /
   Model / Transition FX / Tabs / Rail / Buy bar` с anchor и z-order.
4. **Геометрия:** параметры x/y/scale/perspective/rotate/blur/z-index в
   зависимости от положения выбранного товара. Агент предлагает числа и
   проверяет их по снимку, не ждёт CSS от пользователя.
5. **Motion:** intro, drag, click, settle, scan, buy card text roll,
   reduced-motion fallback и interruption policy.
6. **Данные:** 5 примерных товаров/цены можно создать как mock data только
   при отсутствии настоящего каталога; не выдавать mock за реальные товары.
7. **Responsive:** mobile композиция перестраивается, а не масштабируется.
8. **Редактируемость:** Figma-native tabs, rail, buy bar, text, card slots;
   spatial stage может быть захвачен в плоские слои и доработан.

## Какой путь выбрать

**Режим 1: creative original.** Сначала несколько разных spatial-подходов,
затем авторская версия. Можно выбрать не дугу, а асимметричную «орбиту» или
product museum. Не копируй конкретный VirtualFit.

**Режим 2: exact recreation.** Если пользователь приложил своё точное ТЗ,
сохраняй указанные URL, шрифты, тексты, размеры, последовательность и
тайминги. Рисуй соответствующие статичные состояния в Figma. Не называй
воссоздание в виде ключевых кадров работающей JavaScript-примеркой.

## Минимальный handoff в Figma

```text
Page: Spatial Try-on — Design Exploration
01 / Desktop — Idle
02 / Desktop — Hover
03 / Desktop — Selected
04 / Desktop — Scan / 50%
05 / Desktop — Settled
06 / Mobile — Idle
07 / Mobile — Settled
Components / Tabs
Components / Garment Card
Components / Buy Bar
Notes / Motion & Fallbacks
```

Пользователь должен иметь возможность редактировать строки, цены, компоненты,
размеры, цвета и расположение объектов. Фактическая JS-интерактивность
требует отдельной реализации/поддержки Figma prototype; не обещай её.

## Проверка

- Есть реальная визуальная проверка desktop и mobile, а не только текст.
- На idle понятен CTA и выбранный товар.
- При сканировании модель и товар относятся к одной выбранной вещи.
- В Figma не один fullscreen bitmap, а настоящие слои.
- Motion states подписаны и не перепутаны с live-анимацией.
- Оригинальные Figma-фреймы пользователя не затёрты.
