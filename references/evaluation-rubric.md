# Evaluation rubric

Four evidence categories: OBSERVED (screenshot or tested behavior); SOURCE-SUPPORTED (externally referenced); HYPOTHESIS (testable assumption); CREATIVE PROPOSAL (visual direction).

Per finding:
- ID / page / frame / control
- statement of observed issue
- specific evidence and link or asset reference
- user task affected
- severity: blocker/high/medium/low
- confidence: high/medium/low
- rationale
- proposed fix
- possible regressions
- acceptance criteria and validation method

Qualitative quality dimensions: comprehension, task success, decision support, navigation, trust, accessibility, visual cohesion, distinctiveness, feasibility. Do not average them blindly or fabricate precision. Aesthetic feedback cannot override critical task failures.

For concept selection rank each direction against goals and practical constraints. Include distinct assumptions.
