# Definition of Done for frontend-only deliverable

- [ ] Local startup command works and build passes (if available).
- [ ] Approved Figma target referenced by URL/frame; visual comparison performed or explicitly blocked.
- [ ] Required screens/routes responsive 390/768/1440 and semantic.
- [ ] Visible and keyboard-usable core interactions; labels, focus, errors, reduced motion.
- [ ] 3D/mobile/fallback branch tested; event loops/listeners disposed, no accidental scroll lock.
- [ ] All mock states clearly labeled; no claim of live orders/payments/auth.
- [ ] Images, fonts, 3D assets included or declared external with license/dependency.
- [ ] `npm run build`/tests results and any known issues documented.
- [ ] How to run, project tree, change log, open integration tasks delivered.
