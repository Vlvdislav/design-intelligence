# Commerce benchmarks — use principles, never copy UI

## User-named anchors

- **Yandex Market (`https://market.yandex.ru/`)** — user likes clear clicks, understandable forms, sections, action hierarchy. Evaluate discoverability, search, category navigation, filter controls, PDP offer information and feedback. Source: user preference, not experimental proof.
- **Ozon (`https://www.ozon.ru/`)** — user likes advanced and technologically dense marketplace. Evaluate range of features, promotional blocks, product discovery and complex information prioritization. Try a lighter interpretation, not an indiscriminate copy.
- **MotionSites** — artistic reference for interactions, motion and 3D; not evidence that a dense marketplace should use 3D navigation everywhere.

## Evidence ledger per reference

`URL | page and date captured | viewport | user goal | observed behavior | screenshot/asset ref | proposed adaptation | UX hazard | confidence`.

Never claim a pattern exists on current live Yandex/Ozon if page cannot be inspected. Product documentation can describe known structures; mark live appearance unverified. Reject invented conversion numbers.

## Evaluation axes

1. Search and browse discoverability (zero-results, suggestions, spelling, filter scope).
2. Category tree and filter literacy (selected state, reset, facet count, mobile drawer).
3. Cards (photo, price, variants, stock, seller, delivery, labels; avoid noise).
4. PDP information scent (image gallery, variants, dimensions/attributes, offers, seller trust).
5. Cart / checkout (total price, delivery method, payment, error recovery, confirmation).
6. Promo and recommendations (recognizable advertising, no misleading discount claims).
7. Long tail, poor network, keyboard-only, coarse pointer, assistive technologies.

## Creative opportunities with commerce guardrails

- Airy, visual-first hero: make brand, category and first action visible; do not hide search.
- Product orbit / spatial showcase: limited promotional collection or PDP exploration; preserve grid alternative, keyboard and reduced motion.
- Interactive 3D inspection: useful when shape/material/detail affects purchase; plain images alternative.
- Scroll narrative: explain new/complex product; do not delay an obvious purchase CTA.
- Large typography: use it to establish hierarchy, not as filler or accessibility obstacle.

## Failure tests

Can a new user find one item, filter to a specification, tell the price and delivery conditions, choose a variant and reach the expected next step? If any essential step depends on knowing a hidden gesture, revise the concept.
