# Пример входного брифа для маркетплейса Fresska

> Это только пример для Fresska. Нельзя автоматически переносить его требования на другие проекты.

- Продукт: мультикатегорийный маркетплейс с премиальной визуальной идентичностью.
- Бренд: фирменный фиолетовый, маскот и текущая дизайн-система важны; нельзя придумывать другие точные цветовые токены без доступа к источнику.
- Особенность каталога: **в листинге нет быстрой кнопки добавления в корзину**, действие доступно на странице товара.
- Типографика: при наличии использовать существующую Fresska Sans Text; оценивать кириллицу, число весов и доступность в Figma. Если локальная гарнитура отсутствует в Figma, не подменять её незаметно.
- Дизайн: необычная композиция, выразительный, но удобный e-commerce; приоритет изображений над длинными рекламными текстами.
- Экраны: главная, каталог, товар, корзина, checkout, мобильный адаптив.
- Checkout: отдельный экран; для текущего утверждённого сценария доставки — пункт выдачи СДЭК, не придумывать курьерскую доставку/ручное назначение даты.
- Ограничения: сохранять бизнес-функции и удобство поиска/фильтрации, не превращать всё в постер.
- Рекомендуемый старт: 3 отдельные mobile концепции → показать через ImageGen → выбрать → native Figma.

## Пример запроса

```text
$visual-art-director Переработай мобильный каталог Fresska. Вот исходный
Figma frame: [ссылка]. Сохрани бизнес-функции и отсутствие быстрого
добавления в корзину. Исследуй 2025–2026, предложи 3 структурно разных
арт-направления и покажи реальные отдельные концепты через ImageGen.
Используй брендовые токены из файла, обоснуй типографику. В Figma пока
ничего не записывай.
```
