# Example test: Fresska — senior UX + creative exploration

User goal: redesign commerce pages to feel premium, coherent, visually memorable while retaining trustworthy purchase flow. This is an example only; inspect current user-approved Figma/source before implementing.

Known user constraints at drafting time (review against current project):
- Marketplace for direct sellers; desktop content width 1440px; premium own identity, not cloned from Ozon/Yandex Market.
- In catalog product list: **no quick Add to Cart**; add item on PDP.
- Cart page lists cart items; separate checkout page.
- Checkout uses SDEK pickup points in approved scope, not fabricated courier or delivery-date selection.
- More imagery, less filler text; coherent responsive rules; light and dark themes; current mascot/colors to be sourced from files, not guessed.

UX research flow: discovery → category → filter → PDP → cart → SDEK selection → payment UI → confirmation, respecting verified capabilities.

Task: Create 3 DIFFERENT concepts for Homepage + Catalog + PDP hero; editorial experiment allowed on home and PDP only, avoid 3D in mandatory filters. Show Figma versions and assess preference, findability, first click and product details legibility. Do not claim conversion uplift from visual voting.

Potential ideas to TEST, not mandate:
A: Utility-first editorial — clean functional navigation, bold product imagery.
B: Airy Tech — modular richness reminiscent of Ozon feature coverage but with stronger spatial whitespace.
C: Curated Spatial — an immersive product showcase on homepage that gracefully falls back to standard browsable catalog.

Handoff selected approved concept to `$creative-frontend-engineer`, no backend or real payments.
