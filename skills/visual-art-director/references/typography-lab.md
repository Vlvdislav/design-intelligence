# Typography Lab — проверка реальной пары

## Семь проверок

1. **Язык:** полная кириллица/латиница, ё, ₽, цифры, знаки процентов, диапазоны, товарные артикулы.
2. **Доступность:** конкретная гарнитура и веса действительно существуют и доступны для текущего Figma-клиента. При Figma MCP использовать возможности официального `figma-use` и `figma.listAvailableFontsAsync()` до обещания точной пары.
3. **Скелет:** длина строки, ритм заголовка, высота строчных, ширина цифр, форма кириллических знаков.
4. **Контраст ролей:** display/text/utility различаются, но не спорят; может быть одна гарнитура с разными оптическими ролями, необязательно две семьи.
5. **Реальные сценарии:** заголовок, фильтр, название товара в 2–3 строки, длинная цена, цена со скидкой, кнопка, таббар, описание, error state.
6. **Мобильная проверка:** длинный русский текст без обрезания, line-height, плотность, минимально читаемые кегли, сочетания весов.
7. **Лицензия:** если пользователь собирается публично использовать шрифт, не делай необоснованных заявлений о бесплатности. Указать «лицензию проверить», если не подтверждена.

## Процесс

- Выдели два-три направления: сдержанная ясность, editorial expressiveness, геометрическая технологичность, humanist warmth и т.п.
- Подбери семьи **по свойствам**, а не по популярности.
- Для каждого зафиксируй название, предполагаемые веса, задачи и риски.
- Проверь визуальный образец на одинаковом UI-контенте. Если imagegen рисует условные буквы, это НЕ доказательство точной гарнитуры.
- Для Figma — используй нативные текстовые слои и доступные точные fontName; недоступные шрифты заменяй ближайшими с явным указанием замены, а не молча.

## Системные принципы

- Выразительность возможна полностью без засечек; не навязывай антикву ради «премиальности».
- Безосновательное смешение 3+ шрифтов — запах шаблона.
- UI-размеры, плотность и межстрочные интервалы должны образовывать шкалу, а не набор случайных чисел.
- Не предлагать 80px заголовок мобильного каталога, если он оставляет ноль места товару и функциональности.
- В ценах важна разборчивость цифр; не уничтожай коммерческий UX чисто декоративным display-шрифтом.
- При уже заданном бренд-шрифте сохраняй его в первом направлении и сравнивай с обоснованными альтернативами.

## Отчёт в 2 строки на вариант

`Typography X: [family, weight] для display + [family, weight] для UI. Почему подходит: [...]. Проверено: кириллица / Figma availability / licensing status: [да/нет/неизвестно].`
