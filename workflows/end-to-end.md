# End-to-end workflow

## Phase 0 — Target and scope
Determine whether requested audit, research, journey, concepts, motion or actual Figma edits. Read appropriate expert modules and product profile.

## Phase 1 — Capture
Retrieve target screenshot and Figma node metadata, identify viewports and states. Never claim to know hidden interactions. Preserve baseline.

## Phase 2 — Product model
Audience, JTBD, business intent, first action, core journey, differentiation, constraints. For marketplace examine browse/search → narrow → PDP → cart → delivery/payment.

## Phase 3 — Research
Behavioral comparison with competitors and credible UX literature; visual comparison with adjacent industries. If Mobbin accessible, use single-screen vs flow vs section search appropriately; inspect real screenshots. Capture links and notes.

## Phase 4 — Diagnosis
Run the UX audit rubric. Keep evidence, user impact, severity, confidence, implementation effort and validation path. Separate critical UX defects from subjective art direction.

## Phase 5 — Concept exploration
Develop at least 3 genuinely distinct directions when asked for creative exploration. Write complete concept briefs with navigation invariants, visual language, motion strategy and responsive implications.

## Phase 6 — Decision
Compare concepts against product goals. Challenge visually impressive but hard-to-use elements. Select or recommend grounded hybrid.

## Phase 7 — Figma execution (opt-in)
Read official Figma integration skills, duplicate source, reuse real tokens and components, create editable layers, produce screenshots and node references. Never overwrite without permission.

## Phase 8 — Independent QA
Test tasks, copy, responsiveness, accessibility, reduced motion and brand consistency; examine before and after. Log unresolved assumptions and propose practical user tests.

## Phase 9 — Delivery
Executive summary, ranked findings, research sources, 3 concept alternatives if applicable, exact Figma outputs if changed, implementation risks and acceptance checklist.
